# P2 eşit katman karışımı takip çalışması

Bu dizin P2 koşulunun dondurulmuş çalıştırıcısını, CPU doğrulayıcısını ve toplulaştırılmış nihai raporunu içerir.

P2, son dört gizli katmanı 0,25 sabit ağırlıklarla birleştirir ve ardından maskeli ortalama uygular. Takip çalışması 30/30 yeni worker ile tamamlanmış, resmî teste erişmemiş ve seçim amacıyla kullanılmamıştır.

Nihai rapor yalnızca toplulaştırılmış metrikler ile worker kimlik/hash özetlerini içerir; ham metin, gold etiket veya örnek düzeyindeki tahmin içermez.
